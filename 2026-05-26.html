📌 议题一 · AI产品与平台动态

Microsoft — Copilot Studio计算机使用智能体正式发布

微软宣布Copilot Studio中的计算机使用智能体（Computer Use Agent）正式发布（GA），可让AI智能体通过视觉界面直接操作网站和桌面应用，处理缺乏API接口的遗留系统。同时支持凭证安全管理、模型选择和可审计的会话重放，Token消耗降低约50%。

来源：来源：Microsoft Copilot Blog

Microsoft — Windows Agent Store发布，开发者分成85%

微软在Build大会上推出Windows Agent Store，为AI智能体提供分发平台，开发者可获得85%的收入分成。Adobe和Zoom已成为首批合作伙伴。这标志着Windows从操作系统进一步演变为AI智能体的运行和交易平台。

来源：来源：StudioGlobal

Microsoft — Windows AI Studio 2.0支持本地模型部署

Windows AI Studio 2.0发布，支持在Copilot+ PC上完全本地运行小型语言模型（如Phi-4 Mini），无需联网、数据不离开设备。这为企业提供了在隐私合规前提下使用AI的新选择。

来源：来源：AllInOneAICenter
📌 议题二 · AI公司组织、人才与治理

渣打银行 — 计划到2030年裁员近8000人

渣打银行5月19日宣布，计划到2030年将公司职能部门岗位减少15%以上，涉及近8000个工作岗位。渣打成为最新一家因AI技术运用而实施大规模裁员的全球金融机构。此前新加坡星展银行已宣布未来三年裁员近4000人，汇丰也在考虑影响约2万岗位的AI驱动重组计划。

来源：来源：经济参考报

Microsoft — 向8000+资深员工启动自愿买断计划

微软致信员工称，将面向年龄与在职年份总和达70年及以上的长期员工启动自愿买断计划，据估算涉及超8000人。CFO艾米·胡德在财报电话会上表示："我们会继续调整运营方式，预计员工人数将同比下降。"

来源：来源：经济参考报
