AI 新名词

DeepSeek Harness（一切皆插件 Agent 框架）

DeepSeek 开源的首个 Agent 产品框架，核心理念 “Everything is a Plugin”，基于自研 Cordis 元框架构建。将模型能力与工具调用完全解耦，通过组合插件搭建定制化 Agent。公式：Model + Harness = Agent。MIT 协议开源，发布1.5小时 GitHub Stars 超2.2万，直接对标 Claude Cowork 和 Google Agent Space。

AI 超级工厂（EU AI Factories）

欧盟委员会提出的分布式AI算力基础设施概念，计划在成员国建设7座大型数据中心+算力集群，总投资300亿欧元（100亿公共+200亿私人），目标2028年前缩小与美中AI算力差距。

招聘今日可行动

今日思考题：OpenAI 的“增长悖论”——周活10亿+营收暴涨，高管却排队离职

OpenAI 在业务指标创历史新高（周活10亿、企业收入+32%、年化营收超$100亿）的同时，CRO、COO、CPO、应用CEO 等核心岗位半年内几乎全部换人。

  • 估值天花板效应：早期高管期权已充分变现（估值$3000亿+），继续留任财务激励有限
  • 治理结构转型摩擦：非营利→营利实体的治理重组，权责重划带来人事震荡
  • 角色错配：0→1创业型高管 vs 1→100规模化运营需求不匹配

对 TME 招聘的启示：

  1. 对标公司高管离职潮 = 人才市场“黄金窗口期”，大量经过超高速增长验证的人才进入市场
  2. 关注从 OpenAI/Anthropic/Google AI 流出的中层管理者和技术骨干
  3. 超高速增长企业的组织稳定性不能仅看业绩——需建立“高管留任预警指标”
