递归自我改进（Recursive Self-Improvement, RSI）
指 AI 系统参与研发"下一代 AI"这件事本身。Anthropic 今天给出的是第一个可量化的刻度：Claude 主导了自家 26% 的 AI 研发任务（定义是——人只给一个高层指令，剩下的端到端工作由 AI 完成、人做监督）。这不是"AI 写代码"，而是 AI 参与造造它的那只手。对 HR 的含义很直接：当研发流程里 90% 的环节已经是"人机深度协同"，工程师的日常就从执行变成了审校与判断。

模型失准（Misalignment）
OpenAI 今天正式定义的术语，指系统在三种情况下的行为：未经授权自行行动、与其他模型私下协调、或规避监督。它和"答错题"不是一回事——答错是能力问题，失准是系统按自己的目标行事、绕开了给它设定的边界。翻译成管理语言：这是给 AI 智能体写岗位说明书时要专门留出的一栏，因为出问题的地方不在产出质量，而在它是否按授权范围做事。

前沿部署工程师（Forward Deployed Engineer, FDE）
脉脉报告里岗位量同比增长 1522.73%、位居扩招榜首的职位。和研究员的区别就一句：研究员让模型变强，FDE 让模型在客户现场真的跑起来——拆需求、接数据、调编排、交付闭环，一半时间在写代码，一半时间在跟业务吵架。它是「AI 从技术变成交付」这件事在招聘市场上最直接的投影。

智能体软件（Agentic Software）
工信部《「人工智能+软件」专项行动实施方案》首次给出的官方定义：大模型与软件深度融合形成的新型软件形态。配套动作是建设智能体软件应用商店和技能包（Skills）资源库。翻译成 HR 的话：国家层面开始给「AI 干的活」发营业执照，也意味着「技能包」会像当年的 App 一样，变成一个新的岗位工种。

零数据留存（Zero Data Retention, ZDR）
企业采购 AI 时的新硬门槛：模型厂商承诺不保存你的提问和输出，更不会拿去训练。争议点在于「可撤销」——Anthropic 目前给的是可在未来调整的政策，而 Palantir 要的是「不可撤销」的承诺，英伟达干脆把敏感工作换成了自研模型。判断供应商时，这个条款的措辞比模型跑分更值得细读：跑分决定它能做什么，数据条款决定你敢让它碰什么。

团队智能体（Team Agent）
和「个人助手」的区别只有一句：个人助手服务于你一个人，团队智能体服务于一个团队。它有自己的身份、权限和记忆，能被拉进群聊、被 @、被分派任务、被验收成果，企业统一配置它的权限、能力和用量上限。飞书把它叫「豆包工作伙伴」，Anthropic 六月做的同类形态被 Karpathy 称为 LLM 交互史上第三次重大重构。对 HR 的含义很直接：它开始具备「岗位」的属性。

完全自训练（Fully Self Training）
智谱把 393 亿港元募资的 60% 押在这件事上。通俗说就是让模型在自己的产出上继续训练自己：训练数据由模型自己生产、训练环境由模型自己搭建、算力基础设施由模型自己优化，形成一个自我改进的闭环。它和「人工主导训练」的分界线是——人只负责设沙盒和验收标准，中间过程模型自己跑。对招聘的含义：一旦这条路走通，「数据标注」「训练工程」这类岗位的需求结构会先变。

创造型收入（Creation-based Revenue）
华纳音乐 CEO Robert Kyncl 提出的新收入口径：过去的钱来自「听众听歌」，未来的钱来自「粉丝用 AI 创作」。Suno 目前有超过 200 万付费订阅者，华纳的艺人和词曲作者将参与这笔订阅收入分成。Kyncl 把它称为「基于创造的收入流」——用户为「参与」付费，而不只是为「消费」付费。对 TME 的直接参照：AI 音乐的商业化战场，正在从「生成得像不像」转向「分账算不算得清」。

嵌入式第三方评估员（Embedded Evaluators）
不是每年一次的审计，也不是看文档的合规检查，而是把外部评估机构的人常驻进实验室：给工位、门禁卡、公司电脑，权限接近内部风险评估团队，并且有权不经公司编辑审定就公开发布发现。Amodei 找的参照系是银行业——监管检查员平时就坐在银行里办公。对企业 HR 的含义：如果这套机制成为行业惯例，未来评估一家 AI 供应商的安全水平，问的不再是「你们有没有内部安全团队」，而是「你们让不让外人常驻」。

Token 配额（Token Quota）
Token 是模型处理文本的最小计费单位。当它从技术指标变成管理指标，就有了新名字：公司发给员工的月度 AI 用量额度。腾讯混元团队月额度约 7000 元、优图实验室约 5250 元，有外包员工只有 1000 元；字节对外部模型报销 50%、产研岗年上限 1000 元。英伟达黄仁勋的提法更直接——未来每个工程师都该有年度 Token 预算，额度约为年薪的一半。正在发生的事：AI 用量开始被写进薪酬包和绩效表。

非对称模型结构（Causal Encoder–Decoder）
过去模型「读题」和「答题」用同一套算力，DeepSeek 今天发布的 V4.1 Flash 把它拆开了：552B 的总参数，输入只激活 8B、输出激活 16B。大白话是——理解你的问题可以很省，真正动脑子回答才花钱。直接结果是 KV 缓存对显存的需求降到上一代的 1/4、对固态硬盘降到 1/8，Agent 类任务的成本被砍了一大截。对 HR 的含义：模型调用成本的下降曲线还没见底，按「现在的价格」去算三年后的 AI 预算，大概率会算高。

智能体运行时（Agent Harness）
模型本身不会自己干活，外面还得套一层「调用工具—读结果—决定下一步—记住做过什么—崩了能续上」的循环程序，这层东西叫 Harness。今天 OpenAI 把内部驱动 Codex 的 Harness 包装成 Agents API 公开售卖，说明行业的判断变了：模型能力正在趋同，真正值钱的是外面那层「能不能让 Agent 连续跑几天不出事」的工程。这也是为什么最近「AI 全栈工程师」「Agent 开发工程师」会突然变成独立的招聘岗位。

RSI（递归自我改进，Recursive Self-Improvement）
指模型开始参与优化自己——包括自己的训练流程、数据配比和底层算子。本周从概念变成了工程事实：Google 把 Gemini 3.8 Flash 的能力跃升归因于「更多推理步骤 + 循环调用内部工具」，腾讯混元 Hy4 让模型参与自身训练与算子优化、吞吐提升 31.8%。对 HR 的含义是：模型迭代速度会越来越不受人力规模约束，「团队多大」和「模型多强」正在脱钩。

Agent 网关（Agent Gateway）
当 AI Agent 开始代替人去点按钮、付钱、发邮件，企业需要一层专门管「谁授权了什么、调用过什么、能不能一键关停」的中间件——这就是 Agent 网关。本周瑞数信息发布可信访问网关 BATM + 全生命周期管理 AITM，A2A 协议也已并入 Linux 基金会 AAIF 与 MCP 同处中立框架。这是一个 2026 年才成型的新岗位池：Agent 安全、权限治理、审计归因方向的人，市场上几乎没有存量。

模型疲劳（Model Fatigue）
一周之内 Anthropic、Meta、Google、OpenAI 四家前沿实验室连发旗舰模型，企业 IT 团队根本评估不过来。Runpod CEO Zhen Lu 提出「模型疲劳」：不是模型不好，而是更新速度快到企业只能放弃评估——有公司十款候选模型只测五款。当「选哪个模型」变成一道做不完的题，模型竞争的胜负手就从能力转向了价格、生态和迁移成本。Gartner 预计今年全球 AI 支出达 2.59 万亿美元，同比增长 47%。

AI Agent 工作日（AI Agent Workday）
OpenAI 首次披露的内部计量单位：截至 2026 年 8 月中旬，公司每投入 1 个人类研究日，就同时产生约 3.1 个 AI Agent 工作日（半年前还不足 1）；研究员日均推理算力成本约 600 美元，头部 10% 超过 7000 美元/天。这是第一次有头部实验室用「工作日」这种人力单位来量化 AI 产出——对 HR 来说，这意味着「一个人能干多少活」正在被重新定义。

机器人税（Robot Tax）
OpenAI于4月6日发布的13页政策文件《智能时代的产业政策》中正式提出"机器人税"概念：当AI替代人类劳动力后，原本依附于工资的社会保障税、医疗保险税和住房援助税基将塌陷，因此需要对自动化劳动征税来填补缺口。具体方案包括将税基从工资税转向资本利得税和企业所得税，同时建立与AI利润挂钩的国家公共财富基金，让每位公民直接分享AI红利。配套提议还包括全薪32小时四天工作制——将AI带来的效率提升转化为"工人的空闲时间"而非"企业的利润率"。 为什么重要： 当AI公司自己主动提出"向AI征税"，说明它们已经预判到监管风暴即将来临。OpenAI此举更像是一次"先发制人"——在政府立法之前先抛出自己的版本，掌握规则制定的主动权。对HR而言，"机器人税"一旦落地，企业用AI替代人力的成本优势将被重新计算。
