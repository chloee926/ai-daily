6 月 19 日这波更新的主线，是"智能体化"与"范式/开源扩散"两条上半年主线的汇合。OpenAI 把 GPT-5.5 定位为"新一代智能体基座"，Google 用 DiffusionGemma 挑战逐 token 生成范式，智谱 GLM-5.2 以 MIT 协议把开源前沿模型推到全球前三。对企业而言，头部厂商的差异化已不在"谁更聪明"，而在"谁更适合做 agent runtime"和"谁把推理拉到本地"。
🆕 AI新名词

文本扩散模型（Text Diffusion Model）

Google 于 6 月 19 日发布的实验性开放模型 DiffusionGemma 所代表的新范式：不再像传统大模型那样从左到右逐 token 生成，而是从"随机占位 token 的画布"出发，经多轮迭代同时生成整段文本（256 token 段落）。其 26B MoE 版本仅激活 38 亿参数，经量化可在 18GB 显存运行，文本生成速度最高提升 4 倍。 为什么今天值得知道：长期依赖"按 token 计费"的商业模式，本质是惩罚低效使用方。文本扩散把推理从"逐字打字机"升级为"整页印刷机"，可能在本地单用户场景重写成本结构，也迫使闭源 API 重新思考定价逻辑。

📌 议题一 · 模型栈：智能体化 + 范式扩散

🟢 Google DiffusionGemma：突破逐 token 限制

Google 发布 DiffusionGemma，基于 Gemma 4 与 Gemini Diffusion 研究，260 亿参数 MoE，专为最大化文本输出生成设计。它从随机 token 画布出发迭代优化、一次性评估整个文本块并自我修正，在 GPU 上文本生成速度最高提升 4 倍；具备双向注意力机制，量化后可在 RTX 5090 等消费级 GPU 运行。

🔵 OpenAI GPT-5.5：定位"新一代智能体基座"

OpenAI 把 GPT-5.5 定位为理解复杂目标、调用工具、自我检查、把多步任务带到完成态的"智能体基座"。同期 GPT-Realtime-2 语音套件通过 Realtime API 脱离 Beta 向开发者开放；配套的 Prism 科研协作空间基于 GPT-5.2 起对 ChatGPT 个人账户免费开放。

🟣 智谱 GLM-5.2 开源登顶，马斯克 vs 唐杰"隔空对话"

智谱开源 GLM-5.2（MIT 协议，744B 总参数/40B 激活，1M 上下文），在 Artificial Analysis 综合榜单取得 51 分，跻身全球模型前三、登顶开源模型榜首，编程能力全球第三。围绕"中国大模型何时达 Fable 级别"，马斯克预计 2027 Q1，唐杰则表示"不用那么久"，引发全球关注。

🔬 Anthropic 研究三连：AI Fluency Index / Science Blog / NL Autoencoders

Anthropic 发布 AI Fluency Index、Science Blog（Opus 4.7 在 NMR 谱学上追平专用软件）、Natural Language Autoencoders（让模型"思考数字"可读），持续把前沿模型推向科研与可解释性前沿。

📌 议题二 · 基础设施与人才流动

🔷 Amazon 拟对外出售 Trainium3 芯片，直击英伟达

据报道，Amazon 正洽谈将其自研 Trainium3 AI 芯片出售给其他公司的数据中心，把内部 Nvidia 替代方案变成直接的加速器市场打法，标志云厂商自研芯片从"自用"走向"对外变现"。

👤 Noam Shazeer 据报道加入 OpenAI 攻坚新架构

Transformer 共同发明人、曾创办 Character.AI 后回归 DeepMind 的 Noam Shazeer，据报道将加入 OpenAI，攻坚新模型架构、演进 Transformer 本身。顶级架构人才的流向，仍是前沿竞赛的关键变量。

📉 ChatGPT 市占率首破 50%，但 MAU 破 10 亿

Sensor Tower 报告显示 ChatGPT 在 AI 助手市场份额首次跌破/围绕 50%（Gemini 27.7%、Claude 10.3%），同期 ChatGPT 月活突破 10 亿——绝对用户基数仍在高速增长，市场从"垄断"走向"寡头"。

🏥 OpenAI 用 o3 Deep Research 重开 376 例罕见遗传病

OpenAI 协助波士顿儿童医院、哈佛等团队，用 o3 Deep Research 重开 376 例未解罕见遗传病例，经临床遗传学标准复核后确认 18 例新诊断。AI 医疗从 demo 走向"证据汇编"，压缩专家搜索空间。

🧠 Karpathy 三连发：AutoResearch / Knowledge Bases / "agentic engineering"

Karpathy 24 小时内连发三条，指向同一件事：把 agent 从"对话对象"重新定位为"长期运行的 .md 协作者 + 自主循环执行者"，并正式命名 "agentic engineering"。
