01

AI 新名词

RSI（递归自我改进，Recursive Self-Improvement）

指模型开始参与优化自己——包括自己的训练流程、数据配比和底层算子。本周从概念变成了工程事实：Google 把 Gemini 3.8 Flash 的能力跃升归因于「更多推理步骤 + 循环调用内部工具」，腾讯混元 Hy4 让模型参与自身训练与算子优化、吞吐提升 31.8%。对 HR 的含义是：模型迭代速度会越来越不受人力规模约束，「团队多大」和「模型多强」正在脱钩。

Agent 网关（Agent Gateway）

当 AI Agent 开始代替人去点按钮、付钱、发邮件，企业需要一层专门管「谁授权了什么、调用过什么、能不能一键关停」的中间件——这就是 Agent 网关。本周瑞数信息发布可信访问网关 BATM + 全生命周期管理 AITM，A2A 协议也已并入 Linux 基金会 AAIF 与 MCP 同处中立框架。这是一个 2026 年才成型的新岗位池：Agent 安全、权限治理、审计归因方向的人，市场上几乎没有存量。

02

Agent 从「聊天」跨进「代办」

🟡 Meta — 发布个人 AI Agent「Muse」，消费级 Agent 首次拿到数十亿用户级分发

9/9 上线，由 Muse Spark 1.3 驱动，覆盖 iOS/Android/muse.ai/WhatsApp，面向美国 18+ 用户。可代购、订票、填表、发邮件并在后台持续执行；每位用户配独立的 Muse Secure VM，Sentinel 系统审查敏感操作，与 Stripe 合作生成一次性卡号。订阅 20/100 美元两档，Meta 股价盘中涨超 7%。

⚪ OpenAI — ChatGPT Images 2.5 发布，主打「精准编辑」而非重新生成

可单独调整产品、背景、文字元素，主体在多轮修改中保持稳定；新增 Sketch 手绘参考、创作模板；API 推出 Flare 与 Sunburst 两款，前者延迟比上代降低 50%。目前 ChatGPT + API 每周生成图片已超 30 亿张。

⚪ Google — Gemini 3.8 Flash 上线，六周内第三款 Flash，并率先给模型输出加文本水印

主打长周期软件工程与自主 Agent，DeepSWE v1.1 得分 73.7% 逼近 Claude Opus 5 的 74%，API 价格维持 0.75/3.75 美元；同步发布漏洞挖掘专属版本 Flash Cyber。9/10 另有消息：Google 已把文本水印技术用于 Gemini 输出以回应欧盟《AI 法案》，Anthropic 跟进，OpenAI 计划跟进。

🟡 Cognition / Mistral — AI 编程与欧洲大模型同周拿下巨额融资

Cognition（Devin 开发商）完成超 20 亿美元 E 轮、估值 480 亿美元，ARR 四个月从 4.92 亿涨到近 9 亿美元（+83%）；Mistral 完成 30 亿欧元 D 轮，三星电子领投、欧盟 Scaleup Europe Fund 首投，投后 213 亿欧元，创欧洲科技单笔股权融资纪录。估值逻辑已从「参数规模」换成「ARR 增速 × 算力自给」。

🟡 音乐 AI — 国内平台把 AI 作曲做成了「发行闭环」 🎵

网易云音乐「天音 AI 写歌」6 月升级四大功能（宝藏词人、乐评灵感、原声演唱、一键发行），非音乐人也能直接发歌并参与「AI 歌曲专属激励金」；腾讯音乐「启明星」覆盖 AI 演唱/作歌/灵感全链路并推出零乐理门槛的「VEMUS 未音」，QQ 音乐已接入元宝大模型重塑搜索推荐；汽水音乐是目前国内唯一明确支持 AI 音乐变现的平台。Spotify 同期在美/爱尔兰/瑞典 Premium 灰度「Talk to Spotify」对话式点歌。

03

「AI 换人」的账算不平了

🔴 Meta — Project OT 被 Reuters 深挖：砍团队 60% 的计划因 Agent 不达预期而叫停

原计划分两波把部分团队缩编最多 60%，5/20 第一波裁掉约 10%（8000 人），11 月第二波在启动前几小时被扎克伯格取消。内部数据是关键：AI 改动的代码量同比 +220%，但功能交付增长严重滞后；重大线上故障（SEV）同比 +40%，员工排障时间多花 70%，工程师被迫「写 AI 工具去抓另一批 AI 工具造的 bug」；员工好感度从 74% 跌到 55%。CTO Bosworth 内部承认公司在向员工解释愿景上做得「糟糕透顶」，扎克伯格承认「时机判断错了」，并确认今年不再大规模裁员。数千人被重新部署到 AI 优先团队。

🔴 Klarna — 把裁掉的客服重新招回来

此前宣称 chatbot 接替了 700 名客服工作、冻结招聘、通过自然流失减员 22%，但客户投诉机器人回答机械、无法处理退款争议。CEO Siemiatkowski 对 Bloomberg 承认「我们在削减成本上走得太远了」，现已重新招募远程客服，AI 只留着处理常规问题。

🔴 DeepSeek — 开 150 个工程 HC，0 个 AI 研究岗，明确要「即战力」

9/8 发布，全部集中在服务端开发（大模型研究平台、Agent 框架组件、研发效率基建、API、线上服务、数据工程）与 Agent 弹性计算研发（平台开发、底层系统）两个序列，北京为主、部分杭州。重点面向 2-10 年经验资深工程师，还要求「熟练使用 AI Agent 工具开发」且「当 Agent 提供有问题的方案时能敏锐发现并及时介入」。Harness 负责人崔添翼称这是「前所未有的 150 个 HC」。今年目标团队扩到 1000 人（2025 年初核心团队仅约 150 人）。同期 DeepSeek 被证实已聘中信证券筹备科创板 IPO。

🔴 OpenAI / Anthropic — 抢人战场从算法研究员转向企业销售高管

OpenAI 已招入前 Slack CEO Denise Dresser 任首席营收官，另有 Salesforce 高管 Jennifer Mageliner 加入其商业化团队，并开始直接从微软 Azure 挖人；Anthropic 任命前 Salesforce/ServiceNow 高管 Paul Smith 为首席商务官，前 Salesforce/Google Cloud 的 Chris Chaudhary 负责伦敦、东京的银行与金融拓展；Mistral 则成建制挖 Oracle 的项目经理与企业架构师。信号很直接：投资人不再为 demo 付钱，要看可续约的企业合同。

🔴 腾讯 / 华为 / 小米 — 一周内三起关键技术岗人事变动

腾讯任命田永龙进入 CEO/总裁办公室、头衔明确为「混元多模态负责人」，向姚顺雨汇报（田为清华本科、MIT 博士，曾在 Google、DeepMind、OpenAI 任研究员，与姚在 OpenAI 共事过）；原多模态负责人薄列峰转为基础模型部运营负责人。华为开源生态负责人黄之鹏 9/4 官宣离职，结束 12 年华为生涯。小米智能驾驶 L3 技术负责人王乃岩 9/7 离职创业，做「最泛化的具身大模型」，核心研发十余人多为其图森时期老同事。

🔴 行业数据 — 就业结构在变，但不是「AI 让人失业」那么简单

SignalFire《2026 科技人才报告》：头部科技公司总雇员数较 2019 年下降 25%，软件工程师仅下降 11%，且软件工程师在新招中占比从 46% 升到 55%——真正被砍的是市场、设计和产品经理。Stanford 数字经济实验室：AI 没有造成大规模失业，但 22-25 岁在 AI 高暴露职业中的就业比潜在水平低 19%，主因是企业停止招入门级岗位。Layoffs.fyi：今年已有 296 家科技公司裁员近 12.95 万人（Uber 9/2 裁 3300 人、约 10%）。

04

招聘今日可行动

Meta 这件事最反常识的地方，不是「AI 不行」，而是它在同一份内部数据里同时成立两件事：AI 让代码产出涨了 220%，也让线上故障涨了 40%、排障时间多花 70%。换句话说，AI 提升的是「产出量」，消耗的是「兜底能力」——而兜底能力恰恰是资深员工才有的东西。

所以真正的问题不是「AI 能替代多少人」，而是：当 AI 把产出量拉高一倍，你的团队里有没有足够多的人能接住这一倍产出带来的错误？

把这个问题落到招聘上，答案已经写在这周的两条招聘信息里了。DeepSeek 开 150 个 HC，一个 AI 研究岗都不设，全押工程基建，并且明确写「当 Agent 提供有问题的方案时，你能够敏锐地发现并及时介入」——这是一条把「AI 纠错能力」直接写进 JD 的招聘要求。而 SignalFire 的数据说，被裁的是市场、设计、产品，软件工程师在新招里的占比反而从 46% 涨到 55%。

给 TME 招聘的三个可行动项：

一、在核心技术岗 JD 里加一条「AI 产出审校能力」的考察维度。不是问候选人会不会用 Copilot，而是给一段 AI 生成的有隐藏 bug 的代码/方案，看他能不能在 10 分钟内指出问题。这个题目现在还没被市场刷烂，鉴别度极高。

二、重新看待「应届生招不招」这件事。Stanford 的数据说企业在停招入门级岗位，Meta 的数据说 AI 时代最缺的是能兜底的人——这两件事叠加起来是个陷阱：今天省下的应届生 HC，就是三年后招不到的资深工程师。如果同行都在这一栏收缩，逆势保住校招规模反而是成本最低的窗口期。

三、盯住两个几乎没有存量人才池的新方向：Agent 安全/权限治理（对应 Agent 网关这一新中间件品类，中国强制国标《智能体应用安全基本要求》已在制定），以及音乐 AI 的工程化落地（网易云、汽水都在抢发行闭环）。这两个池子小到还能靠「主动出击 + 内部转岗培养」拿到人，等 JD 满天飞的时候就只剩抬价了。

最后留一个没有标准答案的问题：假设明年你老板拿着一份「AI 让人效提升 40%」的报告来找你谈编制，你会先问哪个数字？是产出量，还是故障率？
