AI 新名词

Computer Use Agent（计算机使用智能体）

一种能够像人类一样操作浏览器和桌面应用的AI智能体。区别于传统基于API的自动化，Computer Use Agent通过视觉理解界面、点击按钮、填写表单来完成任务，可处理缺乏API接口的遗留系统。微软Copilot Studio已将该能力推向正式发布。

02

议题一 · AI产品与平台动态

Microsoft — Build 2026发布Copilot Agent Mode

微软Build大会发布Copilot Agent Mode，允许Copilot在IT管理员设定的安全护栏内自主执行多步骤工作流，无需人工逐项确认。现场演示中，Copilot在38秒内完成了一个完整的员工入职流程：创建AD账户、分配软件许可、发送欢迎邮件、安排入职会议。

来源：AllInOneAICenter

Microsoft — Azure AI Foundry扩展至1800+模型

Azure AI Foundry模型目录已扩展至1847个模型，涵盖OpenAI、Meta、Mistral、Cohere、AI21及数十个垂直领域供应商。Anthropic的Claude首次作为第一方选项纳入。Foundry Local也实现正式发布，支持在Windows、macOS（Apple Silicon）和Linux上完全离线运行AI推理。

来源：DigitalDigest

GitHub — Copilot Workspace正式发布

GitHub Copilot Workspace——端到端AI编程环境，可自主规划、编写、测试和提交Pull Request——正式向所有GitHub Enterprise用户开放。微软内部测试显示，Copilot Workspace将"问题提出"到"PR准备审查"的时间平均缩短62%。

来源：AllInOneAICenter
03

议题二 · AI公司组织、人才与治理

美国 — 白宫推迟签署AI监管行政令

据《纽约时报》和美联社报道，白宫讨论签署一项成立AI工作组的行政令，拟在新AI模型发布前引入政府审查机制。但美国总统特朗普推迟签署，原因是担心该行政令可能削弱美国在AI技术方面的优势。这使AI安全监管再次让位于技术竞争。

来源：新华社

美国 — 五角大楼与多家AI公司签署国防合作协议

美国国防部5月1日宣布与SpaceX、OpenAI、谷歌、英伟达等AI公司达成协议，将先进AI技术部署至国防部机密网络中用于合法作战行动。五角大楼称这些协议"加快了美军向AI优先作战力量转型的步伐"。

来源：新华社
