🆕 今日AI新名词：峰谷分时定价（Peak-Valley Compute Pricing）

DeepSeek V4 正式版推出的行业首创 API 定价模式。工作日 9:00-12:00、14:00-18:00 为高峰时段，价格自动翻倍；夜间及周末价格直降 60%。算力正式进入"公用事业化"阶段——像水、电、网络带宽一样按供需动态定价。企业 IT 部门未来可能需要像管理能耗一样管理 AI 算力支出。

💡 每日思考题

今天有两个事件值得放在一起看：

Tom Blomfield 放弃 YC 合伙人这样的"顶流位置"，去 Anthropic 当一个技术员工——因为"算力是最重要的问题"。DeepSeek 把 API 按时段定价，本质是承认算力已成为"稀缺公共资源"。

作为 HR，你的组织里有没有"岗位级别很高但离核心问题很远"的角色？如果顶级人才愿意降级去做真正重要的事，你的组织结构能否容纳这种"反向流动"？
