AI 新名词

Cerebras CS-4 / WSE-3 Turbo

晶圆级（Wafer-Scale）AI推理系统。Cerebras发布第四代产品CS-4，搭载WSE-3 Turbo芯片，单系统算力达750 PFLOPS，官方宣称推理速度比同等GPU集群快30倍。核心技术路线是将整块晶圆做成一颗芯片，避免多芯片互联瓶颈。首批系统预计Q3出货，Jane Street为首个公开客户。

Neocloud（Groq转型模式）

Groq转型后的新商业模式名称。原定位AI推理芯片公司（LPU），现转型为"Neocloud"——用自研LPU提供云推理服务，不再直接卖芯片。本轮$3.5亿A轮、估值$35亿。但创始人及核心硬件团队已转移至英伟达，转型实质存疑。AI芯片公司的"体面退出"新范式。

🔴 企业微信开放 CLI 与 MCP

企业微信正式开放CLI和MCP接口，将消息、日程、文档、审批等十大办公能力开放给AI Agent调用。开发者可通过标准协议让AI代理直接操作企微功能，国内企业办公平台首次大规模接入Agent生态。

来源：企微开发者

🟡 豆包虚拟桌面上线 Windows 版

字节跳动豆包推出虚拟桌面Windows版，AI可通过GUI操作桌面应用——打开软件、填写表格、点击按钮。Computer Use / GUI Agent方向的国内产品化落地。

来源：豆包

🟡 Cursor 发布代码托管平台 Origin

AI编程工具Cursor宣布推出自有代码托管平台Origin，正面挑战GitHub。发布时机耐人寻味——正值GitHub经历长达7小时全球宕机。定位"AI-native代码托管"。

来源：Cursor Blog

🟡 阿里千问办公全面接入企业微信

通义千问办公助手全面接入企业微信，加上此前钉钉和飞书，实现国内三大协同办公平台全覆盖。用户可在企微中直接调用千问进行文档总结、会议纪要、数据分析。

来源：阿里云

⚪ OpenAI 推出 ChatGPT 青少年版 + 暂停 Astra 训练

OpenAI推出面向13-17岁青少年的ChatGPT版本，内置更严格安全护栏；同时暂停代号Astra的前沿模型训练项目。前沿模型安全与用户侧收紧同步推进。

来源：OpenAI Blog

🟡 OpenAI Q2 营收 $67 亿，增速放缓

今天的信号非常明确：

  1. 美团2027校招80%技术岗要求AI能力 — 这不再是"有则加分"，而是硬性门槛。JD中"具备AI工具使用能力或AI项目经验"正在成为标配。TME的27届校招是否需要跟进调整？
  2. Meta裁掉10%传统岗位，AI投入翻倍 — "减人加钱"组合拳表明岗位结构正在重塑。传统软件工程岗缩减，AI应用工程师、Agent开发等新岗位扩张。招聘画像迭代速度够快吗？
  3. Groq核心团队整建制流向英伟达 — AI人才争夺已到"收购团队"级别。当竞对用"整包收购"抢人时，TME的留人策略该怎么升级？
