AI 行业与人才日报

2026-09-11 · 星期五 · 第 103 期
🎵 本期音乐 AI：环球音乐与 ElevenLabs 签下多年授权，共建 AI 混音 / Mashup 平台，艺术家参与为 opt-in、版税可追溯——UMG 手里的 AI 音乐牌已集齐 5 张。同期 Suno 上线首个用华纳、BMG、Believe 授权素材训练的 v6 模型。对国内平台的直接参照是：授权 + 可追溯分账正在取代诉讼，成为 AI 音乐的主流解法。
Meta 周四发内部信，确认裁掉 10% 员工、约 8000 人，同时今年 AI 投入抬到 1350 亿美元；同一天 Gartner 给出一条反着来的预测——到 2029 年，30% 因 AI 被裁的人要被重新招回来，而且更贵。夹在中间的是 Anthropic 那份 154 页报告：AI 已经能被拿去设计导弹和病原体，OpenAI 为此把一位公开警告「人类会永久失去控制」的对齐专家请进了董事会安全委员会。今天这三件事指向同一个判断：AI 正在同时改写「编制表」和「责任表」，而后者我们几乎还没开始准备。
01

AI 新名词

非对称模型结构（Causal Encoder–Decoder）

过去模型「读题」和「答题」用同一套算力，DeepSeek 今天发布的 V4.1 Flash 把它拆开了：552B 的总参数，输入只激活 8B、输出激活 16B。大白话是——理解你的问题可以很省，真正动脑子回答才花钱。直接结果是 KV 缓存对显存的需求降到上一代的 1/4、对固态硬盘降到 1/8，Agent 类任务的成本被砍了一大截。对 HR 的含义：模型调用成本的下降曲线还没见底，按「现在的价格」去算三年后的 AI 预算，大概率会算高。

智能体运行时（Agent Harness）

模型本身不会自己干活，外面还得套一层「调用工具—读结果—决定下一步—记住做过什么—崩了能续上」的循环程序，这层东西叫 Harness。今天 OpenAI 把内部驱动 Codex 的 Harness 包装成 Agents API 公开售卖，说明行业的判断变了：模型能力正在趋同，真正值钱的是外面那层「能不能让 Agent 连续跑几天不出事」的工程。这也是为什么最近「AI 全栈工程师」「Agent 开发工程师」会突然变成独立的招聘岗位。

02

OpenAI 把「脚手架」卖成了产品

🔴 OpenAI — Agents API 开启公测，把驱动 Codex 的那套内部运行时对外开放

开发者一次 API 调用就能起一个云端 Agent：会话持久化、上下文自动压缩、工具检索、多子智能体并行都由 OpenAI 托管，沙箱可选 OpenAI 托管或 Cloudflare、DigitalOcean、Vercel 等 9 家合作方，也可跑在自己的 VPC 里。公测期不额外收费，只按 token 和工具计费。底层 Codex Harness 已于今年 8 月以 Apache 2.0 开源——先开源规格，再卖托管版。

⚪ OpenAI — GPT-Live-1 全双工语音 API 同日转正，定价 0.05 美元/分钟

模型可以边听边说、随时被打断，交互性测试得分从上代的 45.4% 跳到 80.1%；架构上是语音模型负责对话、后端模型负责推理，所以按分钟计费而非按 token。早期用户 Speak 反馈打断率下降 80%，有医疗客户替换掉 2.3 万行代码。

🟡 DeepSeek — V4.1 Flash 正式发布，用非对称结构把成本再砍一刀

552B 参数 MoE，输入激活 8B、输出 16B，原生多模态视觉理解，上下文从 4K 拉到 1M。官方称在 Agentic 基准上超过自家 V4 Pro 以及 GLM5.3、Kimi K3，生成速度提升近两倍；缓存命中输入价格降幅达 60%，闲时价为高峰一半，新价 9/10 12:00 生效，V4 Pro 将于 9/14 起全部路由到 V4.1 Flash 并有序下线。开源权重与技术报告已放出。

🔴 环球音乐 × ElevenLabs — 三大唱片中最硬的一家也下场了 🎵

9/10 宣布多年期授权合作，将基于 UMG 曲库搭建 AI 混音 / Mashup 平台，粉丝可以拿授权曲目做重混、二创和个性化人声体验；艺术家参与为 opt-in（可自行选择不加入），所有使用走 UMG 版权管理系统、版税可追溯。加上已有的 Udio、Spotify、Nvidia、Klay，UMG 手里已有 5 张 AI 音乐牌。同周 Suno 上线首个用华纳、BMG、Believe 授权素材训练的 v6 模型。

🟡 蚂蚁灵波 / 京东 — 世界模型开始往消费级单卡下沉

蚂蚁灵波 9/10 在 7 月的 14B 主模型之外再开源三款：1.3B 的 Small 版面向消费级单卡、可本地实时生成可交互世界，另开放双向 Teacher 模型与因果预训练底座，打通「预训练→蒸馏→轻量部署」全链路；京东 9/9 在 JDD 大会开源实时可交互音视频世界模型 JoyAI-Echo WM，WBench Navigation 158 个案例评测平均 81.7 分。

03

安全治理：154 页报告与一次董事会换血

🟡 Anthropic — 154 页威胁情报报告，第一次把「AI 已经被用来造武器」说清楚

覆盖 2025 年 12 月至 2026 年 8 月、七类滥用：北也门某团伙用 Claude Code 开发制导火箭、射程 2000 公里以上的多级弹道导弹和高超音速滑翔弹（试射失败）；俄罗斯自由职业者用 Claude Code 做出可自主选靶、含「人员」类别、无需人下引爆指令的自杀式无人机集群；伊朗单位用 16 个账号分析 15.5 万条推文、画像 6388 名本国公民；马里一名顾问为情报部门做出覆盖约 2500 万张 SIM 卡的监控平台 Lakana 360。生物方向拦截了 5 起，其中一起是提交给军事研究所的基孔肯雅病毒功能增益研究。

⚪ Anthropic — 报告另一半指向中国厂商的「蒸馏」

自 2026 年 2 月起已关停 7 起源自中国的蒸馏行动。规模最大的一起关联阿里巴巴：3500 多个伪造账号、峰值接近每天 300 万次交互，5—7 月累计观测到 1.51 亿次，产出用于训练 Qwen 3.5 / 3.6 / 3.7；月之暗面把用户请求悄悄转发给 Claude，10 天内约 30 万次；DeepSeek 被指 14 天内转发 1210 万次，且转发内容里包含俄罗斯某政府数据库和中国某警务系统的实时访问凭据。

🟡 OpenAI — 把最尖锐的批评者请进了能否决发布的委员会

9/9 宣布对齐研究先驱 Paul Christiano 加入 OpenAI 基金会董事会及安全与保障委员会（主席为 Zico Kolter），并任营利实体 OpenAI Group PBC 董事会无投票权观察员。他同时是 NIST 下属 CAISI 高级技术顾问、RLHF 奠基者之一（2017—2021 年领导 OpenAI 对齐研究）。他的表态毫不含糊：认为「AI 能力快速提升存在短期内导致灾难性且不可逆控制权丧失的巨大风险」，并称包括 OpenAI 在内的整个行业目前都没走在把风险降到可接受水平的路上。

🔴 Anthropic / Google — 安全研究员继续出走，「房间里没有大人」

继 Anthropic 研究员 Jacob Coxon 上周公开辞职（称公司在「直奔自我改进的超级智能」）之后，NBC News 报道 Anthropic 与 Google 各有一名 AI 安全研究员因安全顾虑离职，并留下「房间里没有大人」这句内部评价。争议的核心不是技术而是治理：安全团队能提意见，但对发布没有否决权。

🔴 美国司法部 — 开始审查英伟达与 Groq 的「技术许可 + 人才引进」安排

去年 12 月英伟达宣布与 AI 芯片创企 Groq 达成 170 亿美元交易，DOJ 正在审查该交易是否通过「不直接收购、只拿技术授权并引入团队」的方式规避常规反垄断审查。这条对 HR 是个新信号：成建制的人才引进本身，正在被当作并购行为来审查。

04

编制与岗位：8000 人、30% 回聘、两个新职业

🔴 Meta — 周四内部信确认裁员 10%、约 8000 人，为 2023 年以来最大规模

同时数千个在招岗位直接不再补人。直接原因是 AI 支出：今年将投入约 1350 亿美元，接近过去三年总和。扎克伯格 1 月就放过话——「2026 年是 AI 开始彻底改变我们工作方式的一年」，并称一个人现在能干过去一个团队的活。美国员工遣散为 16 周底薪 + 每年工龄 2 周，医保延续 18 个月（行业常见为 6 个月）。同期 Meta 通知员工将记录工作电脑上的操作用于训练 AI 模型，已有超 1000 人联署反对。

🔴 Gartner — 给出一条反向预测：30% 因 AI 被裁的人要在 2029 年前招回来

且往往要以显著更高的成本。理由是劳动力总量增长停滞甚至下降，裁员虽有短期财务收益，但会掏空人才管道和组织记忆，最终推高招聘、培训和上手成本。Gartner 同时警告：到 2027 年，75% 只把 AI 生产力收益当作「省成本」的企业，会被把收益 reinvest 到创新、现代化和技能升级上的对手超越。

🔴 人社部 — 第八批新职业公示，「智能体开发员」「具身智能机器人应用技术员」入列

智能体开发员归在「生成式人工智能系统应用员」之下。这条信息量少但信号很硬：AI 应用工作已经被国家职业分类承认分化为编排、评测、运维等独立工程工种，意味着后续的技能标准、培训和职称体系会跟上。对做 JD 的人来说，「Agent 开发」从此有了官方职业名。

🟡 2026 外滩大会 — 全国首个「智能体身份管理（KYA）」国标立项

9/10 在上海开幕，300+ 科技企业参展。蚂蚁集团现场展示原生安全 Agent OS：把任务调度、权限控制放进底座，敏感操作逐次用户确认、可用自然语言设定访问规则；大会同期启动 KYA 国标立项，目标是建立智能体的授权、身份、能力评估、资金安全与责任追溯机制。

05

招聘今日可行动

今天最值得琢磨的，是 Gartner 那条预测和 Meta 那条裁员放在一起的张力：一边是 8000 人现在离场，一边是「30% 的人三年后要被更贵地请回来」。如果这件事真的发生，它不会是一次「撤销」，而是一次「重构」——正如凯捷的一位架构师说的那句：企业裁掉的是岗位，不是任务，等要请回来的时候，请的是「能兜底的人」，不是原来那个人。

这对招聘意味着一个很具体的操作问题：你的离职名单里，有没有一部分人其实应该在三年后以另一种身份回来？

给 TME 招聘的三个可行动项：

一、把「AI 相关裁员」和「常规优化」分开建库。今年被裁的人里，有相当比例是被流程自动化替代的标准化岗位，他们的业务语境和公司记忆是有价值的。建一个 alumni 池、按「是否值得回聘」打标，成本几乎为零，但三年后这是最便宜的一批资深候选人。

二、在核心技术岗 JD 上加一条「AI 产出审校能力」，并且写进笔试题。昨天 DeepSeek 的 150 个 HC 里已经明确要求「当 Agent 给出有问题的方案时能敏锐发现并及时介入」。今天人社部把「智能体开发员」列入新职业，等于官方承认这是一个独立工种。给一段带隐藏 bug 的 AI 生成代码，看候选人能不能在 10 分钟内指出问题——这个题目现在还没被市场刷烂，鉴别度极高。

三、盯住「责任表」这条线刚冒出来的新岗位池。Anthropic 报告里最贵的一句话是「安全团队能提意见，但没有否决权」；同一周 OpenAI 的安全委员会拿到了发布否决权，国内 KYA 国标立项。这三件事合起来，会催生一批此前几乎零存量的岗位：AI 治理、模型审计、Agent 权限与身份管理。这个池子现在小到还能靠主动出击 + 内部转岗拿到人，等 JD 满天飞的时候就只剩抬价了。

最后留一个没有标准答案的问题：假设三年后你的老板拿着一份「回聘名单」来找你，说这些人的薪资要比离职时高 30%——你会怎么定义「哪些人值得」？是按职级，按绩效，还是按「他走了之后有没有人接得住他手上的活」？
